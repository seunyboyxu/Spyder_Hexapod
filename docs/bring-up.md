# ESP32 upload and first calibration

1. Inspect [hardware and power](hardware.md). Replace the inadequate PP3/3A setup before multi-servo motion. Disconnect servo power for wiring, upload and reset. Support the mount/body and verify OE reset inhibition.
2. Choose one complete folder in the [sketch index](../firmware/README.md). For four legs and iPhone, open `firmware/spyder_esp32_ble_four_leg_test/spyder_esp32_ble_four_leg_test.ino`; retain every companion header/source beside it.
3. In Arduino IDE Boards Manager install **esp32 by Espressif Systems**. All four are verified with **2.0.17**; both BLE sketches also build with **3.3.2**. Use ESP32 Dev Module for the generic original board,4MB flash/default approximately1.3MB application partition, or identify the exact manufacturer target first.
4. Install **Adafruit PWM Servo Driver Library3.0.2** and dependency **Adafruit BusIO1.17.4**. BLE/BluetoothSerial, Wire, SPI and Preferences come with the ESP32 core; do not install a separate BLE stack library.
5. Select the USB port and upload with servo power off. If needed, hold BOOT during initial connecting and release when writing begins. Open Serial Monitor at **115200, Newline**. Send `help` and `show`; outputs must be OFF, including when saved calibration loads.
6. For BLE, open **Bluefruit Connect**, grant Bluetooth permission, scan/connect inside the app and open UART. Names: **Spyder-4Leg-BLE** or **Spyder-Leg-BLE**. TX notifications must be enabled. Send newline-terminated commands; do not pair in iOS Bluetooth Settings. Classic versions require an Android/Windows SPP terminal; see their READMEs.
7. With an adequate servo supply and clear linkage, perform the sketch's physical alignment/direction procedure before standing or steps. Use the [four-leg group procedure](../firmware/spyder_esp32_ble_four_leg_test/README.md#calibrate-all-four-legs-together) or [one-leg procedure](../firmware/spyder_esp32_ble_leg_test/README.md#calibration--one-joint-at-a-time). Reference: hip outward, thigh horizontal, lower link down. Start with small moves, correct individual mirrored legs and confirm only what was observed.
8. Record [calibration and supply measurements](templates/calibration-log.md). `off` then `save` retains calibration in ESP32 Preferences. Four-leg and one-leg records are separate. Nothing automatically attaches on load/reset/reconnect.

`cal all` allows unchecked initial four-leg activation; `armall` requires all12 physically checked. `check all` is a human assertion, not sensor feedback. Wait for Ready after each gradual move, and allow settling after immediate attachment. Send commands individually. Support the body for all-four motion: simultaneous `step` is not a balanced gait.

STOP holds and cancels future motion; OFF or urgent ! releases all signals; BLE disconnect/unsubscribe does likewise. Check these with the body supported. I2C/setup faults latch off and require correction/reset. Full command explanations and input-recovery instructions are in each [sketch README](../firmware/README.md).
